---
title: Sync settings, made clear
date: 2026-09-07
---

The sync pane has been rebuilt so every state reads at a glance. Whether you are
connecting a first Mac, adding a second one, or watching a trial run down, the
screen now says what matters in the shape it actually takes.

## What changed

- **A trial counts the days left** as a large number, so the one thing that
  matters is the first thing you see.
- **Subscriptions are shown as price cards**, with the yearly saving computed
  from the real prices rather than claimed.
- **Storage draws a progress bar** once a quota is set, and warns plainly when
  files are waiting because the account is full.
- **Status, account, server, and pending changes** sit in one panel with clear
  labels instead of a scattered list.
- **Notices and errors use the same alert shape** as the rest of the app, so a
  warning looks like a warning everywhere.
- **The whole pane uses the shared panel and field primitives**, which tightens
  spacing and makes the layout consistent with the other settings screens.
