date: 2026-09-07

Notes now have a visual sibling: an infinite board of cards, groups and the lines
between them, for the sketches and flows that a page of text doesn't fit.

## What changed

- **A canvas lives beside your notes** — same folders, same pinning, same place
  in search and the command palette — and opens from the same "New" button.
- **It's stored in the open JSON Canvas format**, so the file in your Markdown
  mirror is a real `.canvas` file: open it in Obsidian and it looks exactly as
  it does in Neo, unchanged.
- **Cards, groups and arrows** — drag to connect two cards, snap to the nearest
  edge, and label the line if the connection needs a word.
- **It syncs like everything else** — the same operation log, the same
  workspace key, arriving on a second Mac the same way a note does.
