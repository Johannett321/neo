---
title: The Sync pane opens again
date: 2026-09-09
---

A fix for 1.6.0. On a Mac that had synced before, the Sync pane sat on
*Looking…* and never drew.

Upgrading a database adds new tables and new columns, and the two are not the
same thing. `CREATE TABLE IF NOT EXISTS` does nothing at all on a machine that
already has the table — so the cursor column 1.6.0 renamed reached a fresh
install and never reached an upgraded one. The pane asked the database for a
column that was not there, the channel threw, and the screen waited for an
answer that was never coming.

Nothing was at risk: it was a read that failed, no work was touched, and every
other screen carried on as normal.

The test that should have caught it now does. It builds a database in the old
shape, upgrades it, and then *draws the pane* — asserting the columns would not
have been enough, because what has to agree is the code that reads them.
